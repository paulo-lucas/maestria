 8b. Verify email

 8c. 2FA setup

Scan the QR code or enter the key, then confirm with a code.

 8d. Recovery codes

Ten one-time codes shown once, with copy and download.

 8e. Log in

Email and password; the 2FA challenge follows.

 8f. 2FA challenge

6-digit code, with a recovery-code fallback and an error state.

 8g. Reset password (request)

Ask for a reset link by email.

 8h. Reset password (new)

New password, confirmed with a 2FA code. Reset never bypasses 2FA.

 11b. Connector offline

Global offline banner; last known state shown dimmed, actions disabled.
