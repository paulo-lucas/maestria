Kill switch

Off

Stop all remote control now

Every connector stops accepting commands from this site right away. Agents keep running on your machines. Only you, on each machine, can turn it off again.

Turn on the kill switch?

Workstation and Laptop reject every command from Maestria right away. Mac mini is offline and gets it as soon as it reconnects. To turn it off, run maestria kill-switch off on each machine.
