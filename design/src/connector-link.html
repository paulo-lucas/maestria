Link a machine

The connector runs next to Maestri on your machine. It opens an outbound connection to Maestria: no open port, no tunnel.

  1. Install the connector One binary for macOS and Windows. Skip this if maestria is already installed.
    macOS Windows Build from source
  2. Run this on the machine The code works once and expires in 9:41.
    K7QF-29MX
    maestria connect --code K7QF-29MX
  3. Confirm on the machine The connector shows the account it is joining (you@example.com). Type y to link it. Give the machine a name, like "Workstation".

    Waiting for the connector…

Got a code from the CLI instead?

You'll still confirm on the machine.

Your machine stays in charge

The connector only runs a short allowlist of actions (prompt the Maestro, answer a Y/n, pause and resume), keeps its own audit log, and has a kill switch that only works locally. Chats, docs and agent previews are sent here encrypted and stored encrypted at rest.
