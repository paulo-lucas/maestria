Atlas

Atlas is the billing service: plans, subscriptions, invoices and the webhooks from the payment provider. Every other service asks Atlas whether a customer may use a feature.

What lives here

  • src/billing: plans, subscriptions, proration
  • src/invoices: numbering, PDF rendering, email
  • src/webhooks: signature checks, retries, dead letters

Run locally

pnpm install
cp .env.example .env
pnpm dev   # http://localhost:3000

Key decisions

TopicDecisionWhy
IDsULIDs everywhereSortable, no coordination
Webhook retriesBackoff up to 24 h, then dead letterProvider retries for 3 days
API styleREST onlyEvery client already speaks it
Webhooks are verified before anything else runs. Never log a raw payload.
