Colors

Neutrals are warm paper in light and cool graphite in dark. Primary actions use "ink" (inverted text color); color is reserved for meaning: status and workspace identity. All tones come from one OKLCH formula, so every hue has the same lightness and contrast.

Type

System font stack (no web fonts), tabular numbers for anything that changes. Base size is 15px on touch screens and 14px on desktop. Mono is used for floor names, commands and terminal output.

Buttons

Primary is ink, one per group. Danger only for destructive or security actions (kill switch, revoke). Controls are 40px tall on touch screens, 34px on desktop.

Workspace tags and status

Workspace tags have a square swatch; status uses a round dot. Shape carries meaning too, so it reads without color: working pulses, needs-you is a diamond, blocked is a square, offline is hollow.

Floors

No numbers. Present floors show state, status text and the agents on them; a bar only when the floor reports progress. Ongoing floors (recurring, indefinite) have a dashed edge and a hatch. Planned floors are dashed and flat. Past floors are one line: landed or cancelled, with the outcome.
