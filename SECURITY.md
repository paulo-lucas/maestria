# Security policy

## Reporting a vulnerability

Please **do not** open a public issue or pull request for a security problem.

Report it privately on GitHub: the repository's **Security** tab, **Report a vulnerability**. Include what you did, what you expected and what happened, and a proof of concept if you have one.

You will get an answer within a few days. A fix ships as a patch release, and machines with automatic updates pick it up by themselves.

## Supported versions

Only the latest release gets fixes. Update with `maestria update` (and `maestria-cloud update` on a hosted server).
