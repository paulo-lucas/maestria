Link a machine

The connector runs next to Maestri on your machine. It opens an outbound connection to Maestria: no open port, no tunnel.

  1. Install the connector One binary for macOS, Windows and Linux. Skip this if maestria is already installed.
    {{icon "i-laptop"}}Downloads Build from source
  2. Run this on the machine The code works once and expires in 10:00.
    ––––-––––
    maestria connect --link ––––-––––{{if .PublicURL}} --cloud {{.PublicURL}}{{end}}
  3. Confirm on the machine The connector shows the account it is joining. Type y to link it. Give the machine a name, like "Workstation".

Your machine stays in charge

The connector only runs a short allowlist of actions, checks every command against a device you approved on the machine itself, keeps its own audit log, and has a kill switch that only works locally. Chats, docs and agent previews pass through here encrypted and are never stored.
